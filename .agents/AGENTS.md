# Project-Scoped Rules & Guidelines

## 🚨🚨🚨 Ενημέρωση για Καλύτερα Εργαλεία (Tool Recommendations)
- Όταν για την εκτέλεση μιας εργασίας απαιτούνται ή προτείνονται καλύτερα εργαλεία (όπως το `smartctl` για NVMe), ο πράκτορας ΠΡΕΠΕΙ να ενημερώνει αμέσως τον χρήστη και να ζητά την άδεια για την εγκατάστασή τους.
- Χρησιμοποιείτε ΠΑΝΤΑ τρία θαυμαστικά emojis (π.χ. 🚨🚨🚨) στην αρχή αυτού του μηνύματος για να τραβήξετε την προσοχή του χρήστη.
